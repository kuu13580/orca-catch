# orca-catch 🐋⚡

> **クレジットカードの利用速報メールから、その日の決済合計額をリアルタイムにキャッチして即座に集計するGoogle Apps Script (GAS) ツール**

![orca-catch UI](/home/kuu13580/.gemini/antigravity/brain/2beddfec-5fb8-4256-a0f3-58b894d78892/ui-preview-with-logo.png)

---

## 💡 開発の背景と目的

クレジットカードやタッチ決済を利用した際、**「使いすぎを防ぐために、使った金額分だけ別の預金口座に都度避けておきたい」** というニーズがあります。

しかし、Moneyforward等の一般的な家計簿アプリは「加盟店からカード会社へ売上確定データが届く（通常2〜3日〜数週間）」のを待ってから明細が反映されるため、**「今日の夜（または翌朝）に口座を移動させたい」というリアルタイムな用途にはタイムラグが大きすぎます**。

`orca-catch` は、決済直後にカード会社から届く **「利用速報メール」** をGASで直接解析。
スプレッドシートなどの外部データベースを一切介さず、**スマホのホーム画面からワンタップで「今日使った合計額」を瞬時に把握**できます。

---

## ✨ 主な特徴

- ⚡ **リアルタイム性**: 決済直後の速報メールから即座に金額を抽出
- 📂 **スプレッドシート不要（ステートレス）**: 面倒なシート設定や定期実行トリガー不要。GAS単体で即座に動作
- 📱 **モバイル最適化 Web App**:
  - 当日の利用合計額を大きく表示
  - ワンタップで金額をクリップボードにコピー（銀行アプリでの振替に便利）
  - 「今日」「昨日」「任意日付（カレンダー）」のワンタップ切替
  - カードごとの小計・件数および利用店舗付き明細リスト
- ⚠️ **サイレント失敗防止（エラー検知）**: メールフォーマット変更等でパースできなかったメールを自動検知して画面上に警告バナーを表示
- 🧩 **プラガブルなストラテジー設計**: 誰でも簡単に新しいカードのパーサーを追加・修正可能
- 📥 **受信トレイを汚さない運用**: Gmailで「受信トレイをスキップ（アーカイブ）」フィルタを設定していても確実に集計可能

## 🚀 セットアップ & デプロイ手順

### 前提条件
- Node.js (v20以上推奨)
- Google アカウント

### 1. リポジトリをクローンして依存関係をインストール

```bash
git clone https://github.com/kuu13580/orca-catch.git
cd orca-catch
npm install
```

### 2. Google Apps Script API の有効化 & clasp ログイン

1. [Google Apps Script ユーザー設定](https://script.google.com/home/usersettings) にアクセスし、**「Google Apps Script API」を「オン」** に変更します（※オフのままだとclaspでエラーになります）。
2. ターミナルでログインを実行します：
   ```bash
   npx clasp login
   ```
   > 💡 **WSL / リモートサーバー環境の場合**: ブラウザが自動で開かない場合は、以下のコマンドを実行して表示されたURLをWindows/Mac側のブラウザに貼り付け、ログイン後に取得したコードを入力してください：
   > ```bash
   > npx clasp login --no-localhost
   > ```

### 3. GAS プロジェクトを作成

プロジェクトのルートディレクトリで以下を実行します：

```bash
npx clasp create --type webapp --title "orca-catch" --rootDir dist
```
※ 完了すると、ローカルに `.clasp.json`（GASのスクリプトIDが記載された設定ファイル）が自動生成されます。

### 4. ビルド & GASへプッシュ

```bash
npm run deploy
```
※ TypeScriptがバンドルされ、`dist/Code.js`, `dist/appsscript.json`, `dist/index.html` がGASへ一括アップロードされます。

### 5. Web App として公開 & アクセス承認

1. コマンドでプロジェクトをブラウザで開きます：
   ```bash
   npx clasp open
   ```
2. GASエディタ画面の右上にある **「デプロイ」>「新しいデプロイ」** をクリックします。
3. 種類の選択（歯車アイコン ⚙️）をクリックし、**「ウェブアプリ」** を選択します：
   - **説明**: `初回デプロイ`
   - **次のユーザーとして実行**: **`自分`**（※必ず「自分」にしてください。アクセスした人が自分のGmailを参照するためです）
   - **アクセスできるユーザー**: **`自分のみ`**
4. **「デプロイ」** をクリックします。
5. **アクセス承認画面の突破手順（初回のみ）**:
   - 「アクセスを承認」をクリックし、ご自身のGoogleアカウントを選択します。
   - **「このアプリは Google で確認されていません」** という警告画面が出ますが、自作GASでは正常な挙動です。画面左下の **「詳細」** をクリックし、**「orca-catch（安全ではないページ）に移動」** をクリックします。
   - 権限（Gmailの読み取り）の確認画面が出るので、**「許可」** をクリックします。
6. 発行された **「ウェブアプリのURL」**（末尾が `/exec` のURL）をコピーします。

### 6. スマホのホーム画面に追加

1. コピーしたURLをスマートフォンのブラウザ（iOS: Safari / Android: Chrome）で開きます。
2. ホーム画面に追加します：
   - **iPhone (Safari)**: 画面下の共有アイコン ⎋ > **「ホーム画面に追加」**
   - **Android (Chrome)**: 画面右上のメニュー ⋮ > **「ホーム画面に追加」** または **「アプリをインストール」**
3. ホーム画面のアイコンをタップすれば、いつでも1タップで当日の決済額・内訳が確認できます。

## 🔄 コードを修正・更新したときの再デプロイ手順

パーサーの追加や設定変更を行った場合、GASの仕様上 **「デプロイのバージョン更新」** が必要になります。

```bash
# 1. 修正したコードをビルド＆プッシュ
npm run deploy

# 2. GASエディタを開く
npx clasp open
```
GASエディタで **「デプロイ」>「デプロイを管理」** を開き、
右上の **鉛筆アイコン（編集）** をクリック ＞ バージョンで **「新バージョン」** を選択 ＞ **「デプロイ」** をクリックすれば、同じURLのまま最新コードが反映されます。

## 💡 Tips: Gmailの受信トレイを散らかさない設定

利用通知メールで普段の受信トレイ（Inbox）が埋まってしまうのを防ぐため、Gmailのフィルタ機能を活用するのがおすすめです。

1. Gmailの検索バー右側のフィルタアイコンをクリック
2. 送信元に各カード会社のアドレスを指定（例: `from:(vpass.ne.jp OR mail.rakuten-card.co.jp OR jcb.co.jp OR paypay-card.co.jp)`）
3. **「フィルタを作成」** をクリック
4. **「受信トレイをスキップ (アーカイブする)」** にチェックを入れて保存

> 💡 **ポイント**: `orca-catch` はアーカイブされたメールも自動的に検索対象に含めるため、**受信トレイを一切汚さずにバックグラウンドで集計が動作します**。
> 特定のラベル（例: `label:カード通知`）を付けて隔離したい場合は、`src/config/app.ts` の `labelFilter` に `'label:カード通知'` と指定して再デプロイしてください。
